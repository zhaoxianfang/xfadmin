# XfAdmin 扩展包 · 全面分析

> 本文档对 `zxf/xfadmin` 扩展包做一次系统性分析，覆盖目录结构、组件体系、配置、资源/插件系统、公共参数约定与扩展方式，作为阅读其余架构文档与《组件参考》的总入口。

---

## 1. 包定位

XfAdmin 是一套 **服务端渲染（PHP）的后台 UI 组件库**，对标 INSPINIA 模板，支持 Laravel 与 ThinkPHP 双框架。

- 组件在 PHP 端渲染为 Bootstrap 5 + Tabler 图标的 HTML，前端交互由 `xfadmin.js` / `xfadmin-diy.js` 驱动；
- 不依赖 jQuery（前端为原生 DOM API）；
- 通过 `XfAdmin::component()` 统一入口渲染，所有组件返回字符串或组件实例，可无限嵌套。

当前版本：`config/xfadmin.php` 中 `version = 2.1.0`。

## 2. 目录结构

```
xfadmin/
├── config/xfadmin.php          # 资源配置（assets_url / version / theme / brand / footer）
├── src/
│   ├── XfAdmin.php             # 门面：组件注册表 + 全局方法（page/sidenav/diy/...）
│   ├── Component.php           # 组件基类（defaults/get/attrs/raw/img/uid/e/...）
│   ├── Assets/Assets.php       # 资源与插件管理器（PLUGINS 注册表）
│   ├── Support/                # 助手（DiyRenderer、DemoMenu、...）
│   └── Components/             # 全部组件类
│       ├── Layout/  Navigation/  Grid/  UI/  Form/  Table/  Chart/  Data/  Misc/
├── resources/assets/          # 前端资源（css/js/svg/png/...），由 XfAdminServiceProvider 直接托管
├── demo/                       # 离线演示（php -S demo/router.php 即可预览全组件）
├── docs/                       # 本文档与《组件参考》
└── tools/                      # 文档生成、XSS 审计、资源校验、Playwright 自测
```

## 3. 组件体系

### 3.1 注册与别名

- 组件在 `src/XfAdmin.php` 的注册表数组中声明：`'diy' => Components\Layout\DiyLayoutPage::class`；
- 每个类可有多个别名（如 `topNav`/`topnav`、`dateRange`/`dateRangePicker`）；
- 调用方式：`XfAdmin::diy([...])`、`XfAdmin::dataTable([...])`，别名大小写不敏感；
- **PHP 保留字规避**：`switch` → 类 `Toggle`、`empty` → 类 `EmptyState`，但保留别名。

### 3.3 组件基类 API（`src/Components/Component.php`）

每个组件至少实现 `defaults()` 与 `html()`：

- `defaults()`：返回参数默认值数组（注册表用数组 `+` 合并公共字段）；
- `get($key, $default)`：读取参数（经白名单/安全校验）；
- `attrs($map)`：生成 HTML 属性串；
- `raw($v)`：原样输出内容（HTML/组件/闭包/数组）；
- `e($v)` / `text($v)`：文本转义输出；
- `img($path)`：图片解析（外链/data URI 原样，其余按 `images/` 相对路径）；
- `uid()`：自增唯一 id（`xf-N`，不稳定，需定位时显式传 `id`）；
- 安全校验助手：`enum()`（白名单+回退）、`cssLen()`、`cssColor()`、`cssBackground()`、`safeUrl()`、`gridCol()`、`img()`。

## 4. 配置系统（`config/xfadmin.php`）

通过 `XfAdmin::config($array)` 覆盖，或改配置文件：

| 键 | 说明 | 主要可选项 |

| `assets_url` | 资源基础 URL | `/zxf/xfadmin`、远程 CDN、发布后的 `public/zxf/xfadmin` |

| `theme.layout_width` | 宽度 | `fluid` / `boxed` |
| `theme.topbar_color` | 顶栏色 | `light` / `dark` / `gray` / `gradient` |
| `theme.menu_color` | 侧栏色 | `light` / `dark` / `gray` / `gradient` / `image` |

## 5. 资源与插件系统（`src/Assets/Assets.php`）

- 组件在前端交互依赖第三方库（如 `datatables`、`apexcharts`、`quill`、`leaflet`、`sortablejs`）；
- 每个组件通过 `assets()` 方法声明所需插件 key（如 `['datatables','select2']`）；
- 插件在 `Assets.php` 的 `PLUGINS` 注册表中定义，含 `js`/`css` 文件清单；
- `asset_check.php` 校验：① 组件引用的 key 均已注册；② 注册声明的资源文件均真实存在（含 deps 递归）；
- 资源由 `XfAdminServiceProvider` 的 `AssetController` 直接托管 vendor 包内 `resources/assets`，**无需发布**即可在演示中加载。

常用插件（45 个，完整清单见 `docs/06-附录/03-plugin-index.md`）：`datatables`、`datatables-pdf`、`select2`、`choices`、`quill`、`summernote`、`apexcharts`、`apextree`、`apexsankey`、`echarts`、`jsvectormap-world`、`leaflet`、`googlemaps`、`nouislider`、`daterangepicker`、`dropzone`、`filepond`、`pickr`、`tagify`、`inputmask`、`fullcalendar`、`jstree`、`sortablejs`、`glightbox`、`masonry`、`sweetalert2`、`pdfjs`、`tourguide`、`clipboard`、`tinycon`、`animate`、`spinkit`、`ladda`、`diff`、`simplebar` 等。

## 6. 公共参数约定（所有组件通用）

### 6.1 槽位语义

- **文本槽位**（`title`/`label`/`text`/`value`/`subtitle`/`prefix`/`suffix`/...）：输出前 **自动 HTML 转义**；
- **内容槽位**（`body`/`content`/`footer`/`header`/`actions`/...）：`raw()` **原样输出 HTML**，调用方需自行保证可信。

### 6.2 枚举白名单（全部可选项）

以下参数在绝大多数组件中取值受白名单约束，完整可选项如下（与 `src/Components/Component.php` 的 `ENUM_*` 常量及全组件约定一致）：

| 参数 | 全部可选项 |
|---|---|
| `variant` | `primary` / `secondary` / `success` / `danger` / `warning` / `info` / `light` / `dark` / `link` |
| `variant`（outline） | `outline-primary` / `outline-secondary` / `outline-success` / `outline-danger` / `outline-warning` / `outline-info` / `outline-light` / `outline-dark` |
| `size` | `sm` / `lg`（部分组件支持 `md`/`xl`/`fullscreen`） |
| `placement` | `top` / `bottom` / `left` / `right` / `start` / `end` |
| `breakpoint` | `sm` / `md` / `lg` / `xl` / `xxl` |
| `align` | `start` / `center` / `end` |
| `trigger` | `hover` / `click` / `focus` |
| `position` | `top` / `bottom` / `left` / `right` |
| `direction` | `horizontal` / `vertical` / `up` / `down` / `left` / `right` |
| `theme` | `light` / `dark` / `auto` |
| `orientation` | `horizontal` / `vertical` |

> 每个组件《配置参数》表中已逐参数列出其全部可选项（来自源码 `enum()` 白名单或通用约定）。

### 6.3 安全校验类型

| 助手 | 接受范围 |
|---|---|
| `cssLen` | `数字+单位`（`px`/`%`/`rem`/`em`/`vh`/`vw`/`pt`/`ch`/`fr`） |
| `cssColor` | `#hex` / `rgb()` / `hsl()` / 具名色 / `var(--x)` |
| `cssBackground` | 同上 + 渐变函数 |
| `safeUrl` | 协议白名单（拦截 `javascript:` 等） |
| `gridCol` | 响应式列宽 `['sm'=>6,'xl'=>3]` / 整数 `N` / `12` |
| `img` | 外链 / `data:` / 包内 `images/` 相对路径 |

## 7. DIY 可视化布局器（新增）

`XfAdmin::diyLayoutPage()`（`src/Components/Layout/DiyLayoutPage.php` + `src/Support/DiyRenderer.php`）对标 LayoutIt：

- 左：组件/模板/布局元素面板（按分类折叠、搜索）；
- 中：舞台（拖拽/点击添加，行/列嵌套，属性面板编辑）；
- 右：属性面板（基于 `DiyRenderer::catalog()` 的 schema 全字段可编辑）；
- 顶部：设备预览、撤销/重做、清空、保存草稿（localStorage）、导入/导出、代码生成；
- 代码生成：HTML 视图 / Laravel 控制器 / ThinkPHP 控制器 / 块树 JSON 四种；
- 实时渲染端点：`POST /diy/render` → `XfAdmin::diyRender($payload)`。

前端 `resources/assets/js/xfadmin-diy.js`、样式 `xfadmin-diy.css`。

## 9. 扩展指南（自定义组件）

1. 继承 `Component`，实现 `defaults()` 与 `html()`；
2. 在 `src/XfAdmin.php` 注册表与 `@method` 注解中登记别名；
3. 前端依赖在 `assets()` 中声明插件 key，并在 `Assets.php` 的 `PLUGINS` 注册资源文件；
4. 新增 CSS 必须确认 `app.min.css`（INSPINIA 框架）是否已定义该类；已定义的**不要**在 `xfadmin.css` 重写（尤其 position/width/margin/z-index/background），仅补充框架未定义的类；
5. 改完 `src/` 与 `resources/` 后 `rsync -a --delete` 到消费方 `vendor/zxf/xfadmin/` 才生效；
6. 重新生成文档：`php tools/gen_component_docs.php`。

## 10. 已知约定与陷阱（维护要点）

- 框架 `app.min.css` 的 `:root` 变量（如 `--ins-sidenav-width`）会与 `xfadmin.css` 共用同名类，按需显式重置 margin/padding/position，避免“泄漏”；
- `data-xf-config` 用 `json_encode(..., JSON_HEX_TAG|JSON_HEX_AMP)` 防止 XSS；
- 所有 `data=null` 的辅助列必须 `defaultContent ??= ''`，否则 DataTables 触发 “Requested unknown parameter”；
- DataTable「更多」下拉被裁剪：`xfadmin.js` 的 `initDtDropdownFix` 必须在 `shown.bs.dropdown` 的 `requestAnimationFrame` 内改 `fixed` 定位；
- 组件名避开 PHP 保留字（`switch`/`empty` 已用 `Toggle`/`EmptyState` 规避）。
