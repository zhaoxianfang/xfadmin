# 页面模板（整页级组件与页面配方）

本章覆盖两类"模板"：

1. **整页级组件** —— 输出完整 HTML 文档（`<!DOCTYPE html>` … `</html>`）的组件；
2. **页面配方（Recipe）** —— 常见后台页面的完整可复制代码模板。

> 演示站 `demo/` 提供 11 个可直接运行的页面模板，见 §3。

---

## 1. 整页级组件清单

以下组件**自带 HTML 文档骨架**，可直接 `echo` 输出给浏览器：

| 别名 | 用途 | 是否含完整 `<html>` | 文档 |
|---|---|---|---|
| `page` | 后台整页（垂直/水平布局） | ✅ | [01-layout](01-layout.md#page) |
| `landing` | 营销落地页 | ✅（内部委托 `page`） | [01-layout](01-layout.md#landing) |
| `authPage` + 9 个语义别名 | 认证页（登录/注册/找回/锁屏…） | ✅ | [08-认证与错误页](../04-进阶指南/08-auth-pages.md) |
| `errorPage` | 错误页（400/401/403/404/408/500） | ✅ | [08-认证与错误页](../04-进阶指南/08-auth-pages.md#7-错误页-errorpage) |
| `comingSoon` | 即将上线页 | ✅ | [01-layout](01-layout.md#comingsOon) |
| `maintenance` | 系统维护页 | ✅ | [01-layout](01-layout.md#maintenance) |
| `lockScreen` | 锁屏页（独立组件） | ✅ | [01-layout](01-layout.md#lockscreen) |
| `emptyState`（Layout） | 空状态页 | ❌（片段） | [01-layout](01-layout.md#emptystate) |
| `invoiceView` / `invoiceDetail` | 发票打印/详情页 | ❌（片段，可打印） | [06-data-ecommerce](06-data-ecommerce.md) |
| `profilePage` | 个人资料整页 | ❌（整块） | [08-data-people](08-data-people.md) |
| `accountSettings` | 账户设置整页 | ❌（整块） | [08-data-people](08-data-people.md) |
| `chatApp` / `emailApp` / `outlook` | 应用级整页布局 | ❌（整块） | [09-data-comm](09-data-comm.md) |
| `dashboardGrid` / `widgetsDashboard` / `analyticsDashboard` / `ecommerceDashboard` | 仪表盘整页 | ❌（整块） | [10-data-dashboard](10-data-dashboard.md) |
| `reportPage` / `settingsCenter` / `sitemap` / `terms` / `privacyPolicy` | 报表/设置/站点地图/条款 | ❌（整块） | [07-data-content](07-data-content.md)、[10-data-dashboard](10-data-dashboard.md) |

> ✅ = 可直接 `echo` 输出；❌ = 需放入 `page.content` 或 `card.body` 中使用。

```php
// 输出是否以 <!DOCTYPE 开头

```

## 3. 演示站页面模板（demo/）

运行：

```bash
php -S 127.0.0.1:8900 demo/router.php
# 或（无需 router，index.php 内已内置资源自托管）
php -S 127.0.0.1:8900 demo/index.php
```

| 路由 | 模板文件 | 演示内容 | 核心组件 |
|---|---|---|---|
| `/` | `pages/home.php` | 仪表盘：指标卡 + 面积图 + 时间线 + 表格 | `page`、`row`、`statCard`、`card`、`apexChart`、`activityFeed`、`dataTable` |
| `/widgets` | `pages/widgets.php` | 55 个 UI 基础组件总览 | 全部 `UI\*` 组件 |
| `/apps` | `pages/apps.php` | 业务应用：看板、聊天、邮件、文件管理、发票 | `kanban`、`chatBox`、`mailList`、`fileManager`、`invoiceList` |
| `/tables` | `pages/tables.php` | 静态表格 / DataTables / 服务端模式 / 自定义表格 | `table`、`dataTable`、`tablesCustom`、`dataTableToolbar` |
| `/forms` | `pages/forms.php` | 全部表单控件与布局 | `form`、`input`、`select`、`editor`、`upload`、`wizard`… |
| `/charts` | `pages/charts.php` | Apex / ECharts / 地图 / 树图 / 桑基图 | `apexChart`、`echart`、`vectorMap`、`apexTree`、`apexSankey` |
| `/topnav` | `pages/topnav.php` | 水平顶部导航（多级 + Mega） | `page(layout=horizontal)`、`topNav`、`DemoMenu::topNavMenu()` |
| `/landing` | `pages/landing.php` | 营销落地页 | `landing` |
| `/login` | `pages/login.php` | 登录页（card 布局 + 验证码 + 社交登录） | `signIn`、`captcha` |
| `/auth` | `pages/auth.php` | 认证页矩阵：9 种 type × 3 种 layout | `authPage` |
| `/404` | `pages/error404.php` | 404 错误页 | `errorPage` |

```
/auth?type=two-factor&layout=base
/auth?type=success-mail&layout=card
```

#### ⑪ `/404` — 错误页（`pages/error404.php`）

```php
echo XfAdmin::errorPage(['code' => 404]);
```

---

## 4. 模板复用建议

1. **先选骨架**：后台页用 `page`，认证/状态页用 `authPage`/`errorPage` 系列，营销页用 `landing`；
2. **再选内容块**：从 [组件总览](00-总览.md) 找到对应业务组件（列表/表单/详情/看板/聊天…）；
3. **最后补交互**：优先使用组件内置能力（`data-xf` / 行操作 / 过滤栏 / 批量 / 弹窗），
   避免复制模板里的页面专用 JS；
4. **保持一致性**：同一系统的列表页、表单页、详情页使用相同配方结构，便于维护。
