# 多语言 i18n

> 对应 INSPINIA `misc-i18.html`。纯前端实现：翻译文件 + `data-lang` 属性 + `XFAdmin.i18n` API，
> 无需后端参与，切换即时生效并自动记忆。

---

## 快速上手

**1. 标记需要翻译的元素**（`data-lang` 值为翻译键）：

```html
<span data-lang="dashboards">Dashboards</span>
<span data-lang="menu-title">Menu</span>
```

**2. 切换语言**：

```js
XFAdmin.i18n.set('zh');   // 切换到中文（自动拉取 data/translations/zh.json）
XFAdmin.i18n.set('');     // 恢复页面原始文案
```

就这么简单。切换结果自动写入 `localStorage('xfadmin.lang')`，下次进入页面自动恢复。

---

## 翻译文件

- 位置：`resources/assets/data/translations/{语言码}.json`（随包发布，`/zxf/xfadmin/data/translations/xx.json` 自动托管）。
- 格式：**扁平键值对**：

```json
{
    "dashboards": "仪表盘",
    "menu-title": "菜单",
    "apps": "应用"
}
```

- 包内已内置 7 种语言：`en` `zh` `de` `es` `fr` `it` `ru`（INSPINIA 原始数据）。
- 新增语言：放一个新的 `{code}.json` 即可；键缺失时保持元素原始文案（不会显示键名）。

---

## API 参考 `XFAdmin.i18n`

| 成员 | 说明 |
|------|------|
| `set(code)` | 切换语言。拉取翻译 JSON → 应用到全部 `[data-lang]` 元素 → 写 localStorage → 派发 `xf:lang-changed` 事件。传空串恢复默认。返回 Promise |
| `t(key)` | 取当前语言下某键的翻译（无翻译时原样返回键） |
| `apply(root)` | 对指定 DOM 子树应用当前语言（动态插入内容后调用） |
| `lang` | 当前语言码（空串 = 默认语言） |
| `dict` | 当前语言的翻译字典 |
| `base` | 翻译文件目录 URL。默认从 `xfadmin.js` 的 `<script src>` 自动推导，特殊部署可手动覆盖 |

```js
// 动态插入的内容需要手动应用一次
container.innerHTML = '<span data-lang="apps">Apps</span>';
XFAdmin.i18n.apply(container);

// 监听语言切换
document.addEventListener('xf:lang-changed', e => console.log(e.detail.lang));
```

## Topbar 语言菜单联动

`XfAdmin::topbar()` 的 `languages` 配置项带 `code` 字段时，渲染出的语言菜单自动接线（点击即 `XFAdmin.i18n.set(code)`）：

```php
XfAdmin::topbar([
    'languages' => [
        ['code' => 'zh', 'name' => '简体中文', 'flag' => 'flags/cn.svg'],
        ['code' => 'en', 'name' => 'English',  'flag' => 'flags/us.svg'],
        ['code' => 'de', 'name' => 'Deutsch',  'flag' => 'flags/de.svg'],
    ],
]);
```

## 实现要点与注意事项

1. 首次翻译前会把元素原文备份到 `data-xf-i18n-orig`，因此 `set('')` 能精确恢复默认文案。
2. 仅替换 `textContent`，不会破坏元素内的子结构 —— 请把 `data-lang` 标在**纯文本元素**上（如 `<span>`），不要标在含子元素的容器上。
3. 翻译文件请求失败（404 / 断网）时静默保持原文，不抛错。
4. 页面启动时若 localStorage 中有记忆语言且页面存在 `[data-lang]` 元素，会自动恢复该语言。
